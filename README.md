# 桃園市政監督

追蹤桃園市長政見執行進度與市議員議會質詢的公開平台。所有資料來自一張 Google 試算表，網站只負責讀取與呈現。

## 頁面
- 首頁：政見進度總覽、最新進度、最新質詢
- 政見追蹤：依來源（選舉公報／競選期間說法）、狀態、類別篩選；每項政見有參與局處、目前停在哪個環節、進度紀錄、相關質詢
- 局處：職掌、上下級機關、歷任首長、負責的政見、被質詢紀錄
- 官員：任職紀錄、議會答詢
- 議員：依選區與政黨瀏覽；公報議題 vs 實際質詢主題
- 質詢：依標籤篩選
- 立場與規則

## 設定
只需要改 `config.js`：
- `sheetId`：試算表編輯網址中 `/d/` 和 `/edit` 之間那一串。試算表要設成「知道連結的任何人都能檢視」。
- `mayor`：當選市長姓名。

`sheetId` 留白時，網站會顯示 `data/demo/` 裡的範例資料。

## 資料表
分頁名稱與第 1 列欄名不能改，網站靠它們讀資料：局處、官員、任職、政策、政策局處、進度、議員、質詢。填寫規則見試算表的「說明」分頁。
